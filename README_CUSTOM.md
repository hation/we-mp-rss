# 公众号AI总结功能说明

## 📋 功能概述
对指定标签下的公众号文章进行AI智能总结，并推送到飞书群。

---

## ⚙️ 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **正文提取长度** | 4000字 | 公众号HTML提取纯文本 |
| **目标摘要长度** | 300-400字 | 详细概括核心内容 |
| **LLM max_tokens** | 800 | 限制最大输出长度 |
| **并发线程数** | 5 | 并行生成，提升速度 |
| **LLM引擎** | 火山方舟 doubao-seed-2.0-pro | 通过OpenAI兼容API调用 |

---

## 🚀 使用方式

### 1. 自动执行（推荐）
- **触发时间**：每日 18:00
- **总结范围**：当日00:00之后发布的所有文章
- **推送**：自动推送到飞书
- **代码位置**：`jobs/daily_summary.py`

### 2. 手动触发（按标签+时间段）
**方式一：前端页面操作**
1. 进入「标签管理」页面
2. 找到AI标签，点击「总结」按钮
3. 选择时间范围
4. 勾选「推送通知」
5. 点击「生成总结」

**方式二：API调用**
```bash
POST /api/v1/wx/tags/{tag_id}/summary?start_time={timestamp}&end_time={timestamp}&push_notice=true

Headers: Authorization: Bearer {token}
```

---

## 💾 缓存机制

- **存储位置**：`articles.ai_summary` 数据库字段（TEXT类型）
- **规则**：已生成摘要的文章永久缓存，下次直接使用
- **效果**：避免重复调用LLM，节省成本
- **代码位置**：`jobs/daily_summary.py` 第111-122行，`apis/tags.py` 第268-279行

---

## 📤 推送配置

### 飞书Webhook
- **配置文件**：`config.yaml` → `notice.feishu`
- **消息类型**：纯文本（markdown格式）
- **内容结构**：
  ```
  📰 {日期} AI标签公众号文章总结
  共计 N 篇文章：

  【1】文章标题
  - ⏰ 发布时间: HH:MM
  - 📱 公众号: xxx
  - 📄 摘要: ...

  【2】...
  ```

## 📌 注意事项

1. **正文补抓**：新抓取的文章可能只有标题没有正文，需等待补抓任务执行
2. **去重保证**：同一篇文章只会被LLM处理一次
3. **并发控制**：5线程并行，避免API限流
4. **调度器状态**：确保APScheduler正在运行，否则定时任务不会触发
